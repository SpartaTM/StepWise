Установка Git и первый коммит

Пошаговое руководство по установке системы контроля версий Git, базовой настройке профиля и отправке первого репозитория на GitHub.

План действий (4)

Предпросмотр шагов
1

Скачать установщик с git-scm.com

Перейдите на официальный сайт Git и выберите версию под вашу операционную систему.

2

Запустить мастер установки

Пройдите шаги мастера с рекомендованными параметрами по умолчанию.

3

Проверить версию в терминале

Откройте терминал и выполните команду git --version.

4

Настроить имя пользователя и email

Укажите git config --global user.name и user.email для подписи коммитов.
