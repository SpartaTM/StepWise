# StepWise — Frontend & UI Макеты

Этот архив содержит полную фронтенд-часть платформы **StepWise** (ASP.NET Core MVC Razor Views, дизайн-систему CSS и клиентский JS), а также интерактивные HTML-макеты всех страниц для просмотра в браузере без запуска .NET-сервера.

## Структура архива

```text
StepWise-Frontend-GitHub/
├── StepWise/                  # Файлы для вливания в основной репозиторий бэкенда
│   ├── Views/
│   │   ├── Shared/            # Общий каркас (_Layout.cshtml, _Layout.cshtml.css, Error.cshtml)
│   │   ├── Home/              # Главная (Index.cshtml), О проекте (Privacy.cshtml), Ошибки (HttpStatus.cshtml)
│   │   ├── Instructions/      # Каталог с поиском и фильтрами (Index.cshtml), Детали гайда (Details.cshtml)
│   │   ├── Player/            # Интерактивный плеер прохождения с прогресс-баром (Index.cshtml)
│   │   └── Author/            # Кабинет автора (Index.cshtml) и конструктор шагов (Form.cshtml)
│   └── wwwroot/
│       ├── css/site.css       # Дизайн-система, CSS-переменные, адаптивные карточки и анимации
│       └── js/site.js         # Живой поиск по каталогу, копирование ссылки, прогрессивное добавление шагов
├── mockups/                   # Автономные интерактивные HTML-макеты всех страниц (открываются в браузере)
│   ├── 01-home.html
│   ├── 02-catalog.html
│   ├── 03-details.html
│   ├── 04-player.html
│   ├── 05-author-dashboard.html
│   ├── 06-author-form.html
│   ├── 07-about-and-404.html
│   └── assets/
└── README-FRONTEND.md
```

## Реализованные страницы и функционал UI

1. **Главная страница (`Home/Index`)** — Hero-блок с интерактивным превью прохождения инструкции, CTA-кнопки и карточки преимуществ.
2. **Каталог инструкций (`Instructions/Index`)** — фильтры по категориям, мгновенный клиентский поиск по названию/категории, карточки с оценкой времени и количеством шагов.
3. **Страница инструкции (`Instructions/Details`)** — таймлайн с предпросмотром всех шагов, кнопка запуска плеера и кнопка «Скопировать ссылку».
4. **Интерактивный плеер (`Player/Index`)** — динамический прогресс-бар, подсветка текущего шага, отметка выполненных пунктов и экран поздравления при 100% завершении.
5. **Кабинет автора (`Author/Index`)** — таблица созданных инструкций с быстрым запуском, редактированием и подтверждением удаления.
6. **Конструктор инструкции (`Author/Form`)** — прогрессивное раскрытие слотов шагов (от 3 до 10), счётчик заполненных шагов в реальном времени и автодополнение категорий.
7. **Служебные страницы (`Privacy`, `HttpStatus`)** — страница описания проекта и кастомные экраны ошибок (404 и др.).

## Как залить в GitHub

1. Распакуйте содержимое папки `StepWise/` в корень вашего локального репозитория `StepWise` с заменой файлов (папка `mockups/` также может быть добавлена в корень репозитория для демонстрации команде/жюри).
2. Выполните в терминале:
   ```bash
   git checkout -b frontend
   git add .
   git commit -m "feat(frontend): add responsive UI views, styles, JS and page mockups"
   git push -u origin frontend
   ```
